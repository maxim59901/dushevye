# Парсеры комплектующих — простыми словами

## Зачем

Чтобы не набивать каталог руками: программа заходит на сайты поставщиков, забирает название, артикул, цену и ссылку, складывает в общий список и раскладывает по группам (петли, ручки и т.д.).

## Что уже есть

Пробный прогон по **6 поставщикам**, примерно **по 40 позиций** с каждого (всего ~240). Позиции лежат:

- CSV: `data/imports/` (по поставщику + `all-latest.csv`)
- Каталог по группам: `data/catalog/parts.json`
- База seed: `data/catalog/catalog.db` (SQLite)

Группы: петли, ручки, коннекторы, штанги/трубы/профили, уплотнители, раздвижные системы, прочее.

Цены закупа в системе потом видят хозяин, админ и бухгалтер.

|-----------|------|-------------|------|---------|

## Как запустить

Из папки проекта:

```bash
.venv/bin/python -m parsers list
.venv/bin/python -m parsers run --source arabella --max-items 50
.venv/bin/python -m parsers run --all --max-items 50 --max-pages 2
```

Между запросами пауза ~1 секунда (не долбим сайты).

## Чего нет и что дальше

- Полный каталог (тысячи позиций) — увеличить `--max-items` / `--max-pages` и гонять ночью с ПК/шары, **не обязательно** вешать крон на VDS.
- PAULI: цены почти не отдаёт без запроса — либо прайс от менеджера, либо вход в ЛК.
- Сверка дублей между поставщиками и привязка к «нашей» карточке детали — следующий шаг.
- Автозагрузка в живую БД на сервере учёток — когда скажете.

## Важно

Это закупка для внутреннего каталога. Не выкладываем чужие цены на витрину как свои без правил фирмы.
