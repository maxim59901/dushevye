# Учётки и вход (простыми словами)

## Что уже работает
- У каждого сотрудника своя учётка (логин = email).
- Войти: http://178.212.15.231/lk/login.html
- После входа открывается кабинет по роли.
- Новую учётку создают только **админ** или **хозяин** (форма «Приглашение» в их кабинете).
- При создании задаётся роль. Система показывает **пароль один раз** на экране — его нужно сохранить и передать человеку.
- Письма на почту пока **не** шлём (SMTP выключен).
- Сменить пароль можно в кабинете кнопкой «Сменить пароль».
- Сменить роль другому человеку могут только админ или хозяин.
- Журнал действий: админ и хозяин видят всё; остальные — только свои действия.

## Технически (коротко)
- API на FastAPI + SQLite: `/api/auth/*`, `/api/users`, `/api/audit`
- База: `/var/www/dushevye/data/app.db` (не в public)
- Сессия: подписанная cookie `dushevye_session`
- Сервис systemd: `dushevye-api`
- Nginx проксирует `/api/` на приложение
- Стартовый пароль Максима один раз пишется в `/root/dushevye-initial-admin.txt` (chmod 600) при seed
